## Rules

- Never hand-edit a topic table in a MOC. Change the model or a title override in
  `build/vault.mjs` and re-run `build-stubs.mjs`.
- The Widgets section is owned by `build-widgets.mjs`; leave the HTML comment marker
  in place.
- The Dataview block at the top of an area MOC is the live view; the generated table
  below it exists so the MOC still works with the Dataview plugin disabled.
