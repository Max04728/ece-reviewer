## Rules carried by this template

- Frontmatter keys are fixed; see `CONVENTIONS.md` §2.
- Formula expressions are authored **without** `$` — the renderer adds delimiters.
- Problem `steps` become the numbered solution; keep them discrete so the same record
  can feed a `Sets/` drill later.
- `traps` must name a specific failure mode, not general advice.
