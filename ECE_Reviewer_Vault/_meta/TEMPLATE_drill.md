# TEMPLATE — Drill set

Drills live in `<part>/<area>/Sets/` and are **generated from problem records**, not
written by hand. A drill is a selection of `problem` records, shuffled, with answers
behind collapsible callouts.

## Set file shape

```markdown
---
title: "EM-09 Drill — Capacitance from Geometry"
type: drill
area: 05_Electromagnetics
source: [MATH-05-09]
count: 10
updated: 2026-09-23
---

# Drill — Capacitance from Geometry

> [!question] Scoring
> Answer first, then expand. Any problem whose trap you hit goes on the revisit list.

## 1. {{prompt}}

**Given:** {{give}}

> [!success]- Answer
> **{{ans}}**

> [!warning] Trap
> {{trap}}
```

## Sources

| Source | Meaning |
| --- | --- |
| `source: [IDs]` | notes whose problem records populate this drill |
| `count` | how many to include |
| `mode` | `shuffle` \| `tier1-only` \| `traps-only` |

Generated by `build-drills.mjs` (P6). Until then, drills are created manually in this
shape so they can be regenerated later without loss.
