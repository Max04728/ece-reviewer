### 1. What goes wrong here?

> [!success]- Trap
> **Not clearing the peripheral's interrupt flag.** The request stays asserted, the ISR re-enters immediately on return, and the main loop never runs again.

<sub>from ECE-09-06</sub>

### 2. What goes wrong here?

> [!success]- Trap
> **Leaving a cache coherent by assumption.** A DMA write into a cached buffer leaves stale lines in the cache; the buffer must be invalidated or marked non-cacheable.

<sub>from ECE-09-07</sub>

### 3. What goes wrong here?

> [!success]- Trap
> **Treating CPI below 1 as impossible.** A superscalar CPU retires several instructions per clock, so $CPI < 1$ is normal and is not an arithmetic error.

<sub>from ECE-09-01</sub>

### 4. What goes wrong here?

> [!success]- Trap
> **Assuming SPI will report a failure.** SPI has no acknowledge and no address: a wrong or missing slave-select writes real data to the wrong device and the master never knows.

<sub>from ECE-09-10</sub>

### 5. What goes wrong here?

> [!success]- Trap
> **Ignoring daisy-chain position.** Priority in a daisy chain is the physical order of the devices, and an upstream master that never releases the grant starves every device below it.

<sub>from ECE-09-07</sub>

### 6. What goes wrong here?

> [!success]- Trap
> **Sizing the register field from habit.** The field width is $\log_2(\text{number of registers})$, so 32 registers need 5 bits and 64 need 6.

<sub>from ECE-09-05</sub>

### 7. What goes wrong here?

> [!success]- Trap
> **Believing DMA is free.** Cycle stealing still consumes bus cycles, so bus-bandwidth-bound code slows by exactly the fraction stolen; only the instruction-execution cost disappears.

<sub>from ECE-09-07</sub>

### 8. What goes wrong here?

> [!success]- Trap
> **Debouncing with a capacitor and no hysteresis.** A slow RC edge can cross the logic threshold repeatedly, so the input still double-clocks a counter without a Schmitt trigger or firmware confirmation.

<sub>from ECE-09-08</sub>

### 9. What goes wrong here?

> [!success]- Trap
> **Treating an immediate as a memory address.** Immediate mode embeds the constant in the instruction stream; it never costs a data memory access.

<sub>from ECE-09-05</sub>

### 10. What goes wrong here?

> [!success]- Trap
> **Mixing up MAR and MDR.** MAR carries the address out of the CPU, MDR carries data in or out. Swapping them is the standard distractor in register-transfer questions.

<sub>from ECE-09-02</sub>

### 11. What goes wrong here?

> [!success]- Trap
> **Read-modify-write on a GPIO port.** Reading the port returns the pin level, not the output latch, so `PORT |= BIT` can corrupt every other pin on the byte. Use the set/reset register or a RAM shadow.

<sub>from ECE-09-08</sub>

### 12. What goes wrong here?

> [!success]- Trap
> **PWM frequency and duty resolution trade off.** At a fixed timer clock both come from $ARR + 1$, so a 16-bit timer cannot give a 1 Hz PWM with 16-bit duty resolution. Choose which one the application needs.

<sub>from ECE-09-09</sub>
