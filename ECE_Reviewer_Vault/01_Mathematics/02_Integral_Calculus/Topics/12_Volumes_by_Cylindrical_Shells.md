# 12 — Volumes by Cylindrical Shells

> [!abstract] Scope
> Compute volumes of revolution using cylindrical shells, and choose between shells and washers.

## Core Concept

> [!tip] Intuition
> Instead of stacking flat disks, wrap thin cylindrical shells around the axis. Each shell is an unrolled rectangle: circumference times height times thickness. Shells are the method of choice when the region is naturally described with the variable running parallel to the axis of rotation.

**The shell element.** A vertical strip of width $dx$ at distance $x$ from the $y$-axis, of height $h(x)$, when revolved about the $y$-axis sweeps a cylindrical shell of volume $dV = 2\pi x\,h(x)\,dx$. The three factors have direct geometric meaning: $2\pi x$ is the circumference, $h(x)$ is the height, and $dx$ is the wall thickness. Reading the formula that way makes it easy to adapt when the geometry changes.

**The shell formula.** $V = 2\pi\int_a^b (\mathrm{radius})(\mathrm{height})\,dx$. For a region between $y = f(x)$ and $y = g(x)$ with $f\geq g$, the height is $f(x)-g(x)$ and the radius is the distance from the strip to the axis of rotation. Note the contrast with washers: shells multiply radius by height, washers subtract squared radii. Choosing the right method is usually about which produces the simpler integrand.

**Shells versus washers — how to choose.** Washers integrate *perpendicular* to the axis of rotation; shells integrate *parallel* to it. So: rotating about the $y$-axis, a vertical strip is parallel to the axis, hence shells; a horizontal strip is perpendicular, hence washers. The practical rule is to pick whichever description of the region avoids solving for the other variable, since that is what prevents splitting the integral.

**Rotation about a vertical line $x = h$.** The radius becomes $|x - h|$. When the region lies entirely to one side of the line, the absolute value is unnecessary and the expression stays simple. Rotating about the $y$-axis is the special case $h = 0$.

**Rotation about a horizontal line using shells.** Rotating about $y = k$ with horizontal strips in $y$: the radius is $|y-k|$ and the height is expressed as a horizontal length $x_R(y)-x_L(y)$, so $V = 2\pi\int (y-k)\,(x_R-x_L)\,dy$. The structure is unchanged — radius times height — only the direction of the strip differs.

## Formulas

| Quantity | Expression | Notes |
| --- | :---: | --- |
| Shell element | $dV = 2\pi(\mathrm{radius})(\mathrm{height})\,dx$ | Circumference times height times thickness. |
| Shells about the y-axis | $V = 2\pi\int_a^b x\,h(x)\,dx$ | x is the radius; h is the strip height to the axis. |
| Shells, general vertical axis | $V = 2\pi\int_a^b (x-h)\,h(x)\,dx$ | Axis x = h. Use \|x-h\| if the region straddles the axis. |
| Shells with horizontal strips | $V = 2\pi\int_c^d y\,\left[x_R(y)-x_L(y)\right]dy$ | Radius is y; height is the horizontal length. |
| Shells about y = k | $V = 2\pi\int_c^d (y-k)\left[x_R-x_L\right]dy$ | Radius measured from the strip to the line y = k. |
| Method choice | $\mathrm{strips} \parallel \mathrm{axis} \Rightarrow \mathrm{shells}$ | Perpendicular strips give washers. |
| Cone check | $V = 2\pi\int_0^h x\left(h-x\right)dx = \frac{\pi h^3}{3}$ | Calibration: rotating y = x about the y-axis. |
| Shell surface analogy | $\mathrm{unrolled\ shell} = 2\pi r \times h$ | The lateral area of a cylinder; useful for intuition. |

## Worked Problems

### P1. Find the volume generated by rotating $y = x^2$ on $[0,2]$ about the $y$-axis using cylindrical shells.

**Given:** shell method; region given in x

**Solution:**

1. A vertical strip at x has radius x and height x^2
2. V = 2pi∫_0^2 x(x^2)dx = 2pi∫_0^2 x^3 dx
3. = 2pi[x^4/4]_0^2 = 2pi(4)

> [!success]- Answer
> **$8\pi$ cubic units**

> [!warning] Trap
> Using the shell formula with the radius and height swapped. Radius is the distance to the axis (x); height is the function value (x^2).

### P2. Find the volume generated by rotating the region bounded by $y = x$ and $y = x^2$ about the $y$-axis.

**Given:** shell method; height is the difference of curves

**Solution:**

1. Intersections: x = x^2 at x = 0 and x = 1
2. On (0,1) the line is above the parabola, so height = x - x^2
3. Radius = x (distance to the y-axis)
4. V = 2pi∫_0^1 x(x - x^2)dx = 2pi∫_0^1 (x^2 - x^3)dx
5. = 2pi[x^3/3 - x^4/4]_0^1 = 2pi(1/3 - 1/4) = 2pi(1/12)

> [!success]- Answer
> **$\dfrac{\pi}{6}$ cubic units**

> [!warning] Trap
> Using washers here. Washers about the y-axis would require solving both curves for x and splitting into two integrals, because the inner boundary changes at the vertex of the parabola.

### P3. Find the volume generated by rotating $y = x^2$ on $[0,2]$ about the line $x = 3$.

**Given:** vertical axis offset from the region

**Solution:**

1. The region lies entirely to the left of x = 3, so the radius of a strip at x is (3 - x)
2. Height of the strip is x^2
3. V = 2pi∫_0^2 (3-x)(x^2)dx = 2pi∫_0^2 (3x^2 - x^3)dx
4. = 2pi[x^3 - x^4/4]_0^2 = 2pi(8 - 4) = 2pi(4)

> [!success]- Answer
> **$8\pi$ cubic units**

> [!warning] Trap
> Using radius x instead of 3 - x. The radius is always the distance from the strip to the stated axis of rotation, not to the y-axis.

### P4. Find the volume generated by rotating $x = y^2$ on $[0,2]$ about the $x$-axis using shells.

**Given:** horizontal strips; axis is horizontal

**Solution:**

1. Strips parallel to the x-axis are horizontal, at height y, with radius y (distance to the x-axis)
2. Solve for the horizontal length: x = y^2, so the strip runs from x = 0 to x = y^2, giving height y^2
3. V = 2pi∫_0^2 y(y^2)dy = 2pi∫_0^2 y^3 dy
4. = 2pi[y^4/4]_0^2 = 2pi(4)

> [!success]- Answer
> **$8\pi$ cubic units**

> [!warning] Trap
> Using vertical strips for rotation about a horizontal axis. Shells require strips parallel to the axis, so for the x-axis the strips must be horizontal.

### P5. The region bounded by $y = 1/x$, $y = 0$, $x = 1$ and $x = 3$ is rotated about the $y$-axis. Find the volume.

**Given:** shell method, straightforward

**Solution:**

1. Radius = x, height = 1/x
2. V = 2pi∫_1^3 x(1/x)dx = 2pi∫_1^3 1 dx
3. = 2pi[x]_1^3 = 2pi(2)

> [!success]- Answer
> **$4\pi$ cubic units**

> [!warning] Trap
> Missing the cancellation of x with 1/x, which turns the integrand into a constant. Recognising this simplifies the integral enormously and reduces error risk.

## Traps & Exam Notes

- **Confusing radius and height.** In $2\pi\int(\mathrm{radius})(\mathrm{height})$, the radius is the distance from the strip to the *axis of rotation*, and the height is the length of the strip. Swapping them gives a wrong answer that still looks plausible.
- **Using shells with strips perpendicular to the axis.** Shells need strips *parallel* to the rotation axis. Rotating about the $y$-axis means vertical strips; about the $x$-axis, horizontal strips.
- **Using radius $x$ for an axis at $x = h$.** The radius is $|x-h|$, not $x$.
- **Forgetting the $2\pi$.** The factor comes from the circumference; a shell answer missing it is off by a factor of about 6.28.
- **Choosing shells when washers are far simpler** (or vice versa). Both are correct; pick whichever avoids solving for the other variable or splitting the region.
- **Not finding the intersections** when the height is a difference of curves. As always, the intersections determine the limits and where the upper curve changes.
- **Sign errors from a negative radius.** If a strip lies on the far side of the axis, $x-h$ is negative. Use the absolute distance, or set up the region so it lies entirely on one side.
